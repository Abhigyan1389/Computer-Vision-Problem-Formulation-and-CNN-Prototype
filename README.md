# Computer-Vision-Problem-Formulation-and-CNN-Prototype
The focus of this part is to understand how CNNs use convolution, pooling, activation functions, and dense layers to learn visual patterns from images
What is convolution ?
Convolution is a mathematical operation used in Convolutional Neural Networks (CNNs) to extract important features from images. It helps the model detect edges, textures, shapes, patterns and defects from an image
Why is pooling used ?
Pooling is used in a Convolutional Neural Network (CNN) to reduce the size of feature maps while keeping the most important information.Pooling is used to make the CNN faster, simpler and better at recognizing important patterns without needing to process every tiny image detail
Why is ReLU commonly used in CNN's ?
ReLU is commonly used in CNNs because it helps the network learn complex patterns, train faster, avoid learning problems and perform bettwe on images
Why are CNN's better than regular feed-forward networks for image data ?
CNNs are better than regular feed-forward neural networks for image data because they are specially designed to understand images efficiently. They can detect patterns, preserve spatial information, use fewer parameters, learn image features automatically
